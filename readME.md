# 👟 Premium Shoe Product Card

A sleek, modern, and conversion-optimized product card component designed specifically for e-commerce shoe stores. This card features a premium card layout, clean typography, customized feature badges, and eye-catching micro-interactions powered entirely by pure CSS.

---

## ✨ Features

*   **Dynamic Card Hover Effects:** The entire card lifts smoothly (`translateY(-8px)`) with an expanded shadow depth on hover for a tactile, interactive feel.
*   **Image Micro-Interactions:** When hovering over the card, the shoe image scales up slightly and applies a subtle rotation (`scale(1.06) rotate(-3deg)`) to create a high-end storefront animation effect.
*   **Premium Badge Overlay:** A dark gradient (`#18181b` to `#27272a`) absolute-positioned badge that highlights exclusivity.
*   **Clean Visual Hierarchy:** Uses a professional color palette ranging from neutral dark slate colors for headings to soft greys for categories and secondary descriptions.
*   **Flexible Feature Tags:** A wrap-around flex layout featuring light-grey background pills that neatly display the shoe's core technical benefits.
*   **Gradient CTA Button:** An eye-catching "Add to Cart" button built with a vibrant linear gradient (`#38bdf8` to `#a855f7`) and an independent hover scaling effect.

---

## 🛠️ Technologies Used

*   **HTML5:** Structured semantic markup.
*   **CSS3:** Custom styling featuring Flexbox, gradients, `absolute` positioning depth, and custom transition cubic-beziers.
*   **FontAwesome (v6.5.1):** For premium vector icons (Brand bolt logo and Cart icon).
